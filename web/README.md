# 课报会答辩演示网页（web/）

把「87 个年代表版本自动对齐模型」做成可现场操作、带数据可视化的单屏网页。技术路线：**纯 R 计算**——R 服务同时托管页面与 API，浏览器只负责显示，不做任何计算。

## 文件构成

| 文件 | 作用 |
|---|---|
| `index.html` | 单屏三栏结构（成果数字条 / 选择与输入 / 结果与算法 / 覆盖度图） |
| `style.css` | 样式，无外部依赖 |
| `app.js` | 交互逻辑：版本、覆盖度图、转换结果全部取自 R 接口；关闭页面通知 R 清理 |

## 启动方式（一体化）

在仓库根目录执行一条命令即可：

```bash
Rscript 年代表转换_API服务.R
# 默认自动命中仓库内 docs/地质年代表.xlsx；显式指定：--xlsx=docs/地质年代表.xlsx
```

- 缺省 `--host=127.0.0.1`、`--port=8787`，一般无需改；也可用 `--port=` 改端口、环境变量 `GEO_XLSX` 指定年代表。
- 依赖包：`httpuv`、`jsonlite`、`readxl`（未装先 `install.packages(...)`）。
- **启动后自动在默认浏览器打开演示页**，无需手动开文件。
- **关闭浏览器标签页即自动停止 R 服务并清理接口**；也可在终端按 `Ctrl+C` 手动停止。
- 页面由 R 同源托管，不存在跨域问题，无需另开静态服务器。

## 接口（R 提供，未改转换算法）

| 接口 | 返回 |
|---|---|
| `GET /` | 演示页（R 托管的 index.html） |
| `GET /health` | 健康检查，前端判断 R 是否在线 |
| `GET /versions` | 版本列表，每项含 `index / name / cover`（cover=该版本非空单元数） |
| `GET/POST /convert?source=&target=&ages=2.59,2.2` | `results:[{input,output,method,stage,lower,upper}]`；method 为「精确匹配」或「插值」，插值带上下控制点坐标供数轴绘制 |
| `GET /shutdown` | 停止服务并清理（关闭页面时由前端自动调用） |

转换规则与 R 脚本一致：源版本列精确匹配优先；未命中取上下相邻控制点做分段线性插值；超出控制点范围不外推。

## P0 已实现（单屏三栏，答辩必做）

- 单屏布局：顶部成果数字条，下方左（选择与输入）/ 中（结果与算法）/ 右（覆盖度图）三栏，无需翻页
- 成果数字条：87 版本 / 118 单元 / 5 级层级 / 1917–2026 / 一步直达
- 源版本、目标版本选择（含机构、覆盖度），支持一键交换
- 单值即时转换（支持逗号分隔多个年龄）
- 一步直达示意：源年龄直接指向目标年龄，至多一次插值
- 插值数轴：标出上下控制点、输入点与按比例换算的输出值
- 结果表：输入 / 输出 / 转换方式（精确匹配·插值标签）/ 所属地层单元
- 右侧「87 版本覆盖度演进」柱状图：按年代顺序（1917→2026）展示各版本划分的单元数 / 118，真实数据

## 参考用例（GTS2004 → GTS2020，需在装有 R 的环境实跑复核）

| 输入 Ma | 输出 Ma | 方式 | 说明 |
|---|---|---|---|
| 2.59 | 2.58 | 精确匹配 | Gelasian 底界 |
| 3.6 | 3.6 | 精确匹配 | Piacenzian |
| 2.2 | 2.195 | 插值 | 1.81–2.59 之间线性换算 |
| 542 | 538 | 精确匹配 | 寒武/前寒武界线 |
| 1000 / -5 | — | 不外推 | 超出控制点范围 |

> 本机未安装 R，以上为同规则离线自检值；自动开浏览器、`/shutdown` 清理、静态托管需在答辩机（装 R）首次启动时实测一次。
