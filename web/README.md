# 演示网页（web/）

把「87 个年代表版本自动对齐模型」做成可现场操作、带数据可视化的单屏网页。技术路线：**纯 R 计算**——R 服务同时托管页面与 API，浏览器只负责显示与交互，不做任何计算。

## 文件构成

| 文件 | 作用 |
|---|---|
| `index.html` | 双页签结构：成果数字条 + 「上传 Excel 批量转换」/「手动输入年龄」 |
| `style.css` | 样式，无外部依赖 |
| `app.js` | 交互逻辑：版本、覆盖度图、转换结果、文件上传全部走 R 接口 |

## 启动方式

**Windows**：双击仓库根目录的 `start-web.bat`（自动找 R、自动补装依赖、自动开浏览器）。

**命令行**：

```bash
Rscript 年代表转换_API服务.R
# 默认自动命中仓库内 docs/地质年代表.xlsx；显式指定：--xlsx=docs/地质年代表.xlsx
```

- 缺省 `--host=127.0.0.1`、`--port=8787`；端口被占用时服务**自动顺延**到下一个空闲端口，实际地址打印在窗口里。
- 依赖包：`httpuv`、`jsonlite`、`readxl`、`openxlsx`、`writexl`（`openxlsx` 是上传功能保留原表格式所必需）。
- **启动后自动在默认浏览器打开演示页**；若自动打开失败，窗口会打印完整地址供手动复制，服务不受影响。
- **出错时窗口停住并显示原因**，等待按键后才关闭，方便截图排错（不会闪退）。
- **关闭浏览器标签页约 90 秒后服务自动停止并清理端口**；也可在终端按 `Ctrl+C`。网页每 5 秒发一次 `/ping` 心跳，服务端据此判断页面是否还开着；若浏览器始终没打开过（从未发心跳），服务不会自杀。
- 页面由 R 同源托管，不存在跨域问题，无需另开静态服务器。

## 接口（R 提供，未改转换算法）

| 接口 | 返回 |
|---|---|
| `GET /` | 演示页（R 托管的 index.html） |
| `GET /health` | 健康检查，前端判断 R 是否在线 |
| `GET /versions` | 版本列表，每项含 `index / name / cover`（cover = 该版本非空单元数） |
| `GET/POST /convert?source=&target=&ages=2.59,2.2` | `results:[{input,output,method,stage,lower,upper}]`；method 为「精确匹配」或「插值」，插值带上下控制点坐标供数轴绘制 |
| `POST /inspect-file` | 上传探测，返回 `sheets:[{sheet, columns, rows}]` |
| `POST /convert-file` | 上传批量转换，返回统计、`preview`（前 60 条）与结果文件 base64 |
| `GET /ping` | 网页心跳，服务端据此判断标签页是否已关闭 |
| `GET /shutdown` | 停止服务并清理 |

转换规则与 R 脚本一致：源版本列精确匹配优先；未命中取上下相邻控制点做分段线性插值；超出控制点范围不外推。

> `source` / `target` 既可传版本列名，也可传 `/versions` 中的序号。注意用序号时先看覆盖范围——早期版本划分的单元很少，输入年龄超出其控制点范围会返回失败。

## 已实现功能

### 页签一 · 上传 Excel 批量转换

- 拖拽上传、点击选择，也支持在页面内 `Ctrl+V` 粘贴文件；仅接受 `.xlsx` / `.xls`，上限约 40 MB（前端与服务端双重校验）。
- 上传后自动解析工作表清单，逐个显示列名与行数，供下拉选择。
- 年龄列智能预选：列名含「年龄 / age / 年代 / Ma」的自动选中。
- 源版本 / 目标版本下拉（含序号、覆盖数），支持一键交换；下拉项旁实时显示该版本覆盖单元数与百分比。
- 转换后显示统计（总行 / 成功 / 无法转换 / 空值或非数值）、明细预览与新增列名。
- 结果以**下载**形式返回，浏览器端用 base64 还原为 Blob 触发下载；**绝不覆盖你上传的原文件**。
- 结果文件在原表右侧追加 3 列：目标年龄、`_方式`、`_所属单元`；优先走 `openxlsx` 以保留填充色与列宽。
- 格式保留情况如实提示：源文件含批注时明确告知「批注 / 图形无法保留（数据完整）」；走 `writexl` 兜底时告知「结果为纯数据表」。
- 多工作表安全：只在选定的工作表追加新列，其余工作表原样保留（已实测验证）。

### 页签二 · 手动输入年龄

- 输入框改为多行 `textarea`，支持逗号、空格、分号、顿号与**换行**分隔——从 Excel 复制一整列直接粘贴即可（实测 117 个年龄一次通过）。
- 一步直达示意：源版本 → 目标版本，显示精确匹配 / 插值条数。
- 插值数轴：标出上下控制点、输入点与按比例换算的输出值（仅插值时显示）。
- 结果表：输入 / 输出 / 转换方式（精确匹配·插值标签）/ 所属地层单元。
- 支持 `Ctrl+Enter` 快捷转换。

### 公共

- 顶部成果数字条：版本数与地层单元数**取自 `/health` 与 `/versions` 的真实返回值**（单元数用各版本覆盖数的最大值，避免把表头行计入），非硬编码。
- 右侧「版本覆盖度演进」柱状图：按年代顺序展示各版本划分的单元数 / 118，三档配色（≥90 / 40–89 / <40，实测分别为 36 / 14 / 37 个版本），悬停查看版本名。
- 顶栏实时显示 R 服务连接状态。

## 已知限制

- **批注无法保留**：`openxlsx` 4.2.x 的 `loadWorkbook()` 不解析批注部件。服务已在保存前清理批注遗留的悬空引用，避免产出文件被 Excel 判为「已损坏」，但批注内容本身不会出现在结果文件里。数据与填充色等格式不受影响。
- **不支持 CSV**：仅 `.xlsx` / `.xls`。CSV 请先在 Excel 中另存为 `.xlsx`。
- **单文件单次**：一次处理一个文件的一个工作表；需要处理多个表时分别上传。

## 参考用例（本机 R 4.5.0 实测）

### GTS2004 → GTS2020

| 输入 Ma | 输出 Ma | 方式 | 说明 |
|---|---|---|---|
| 2.59 | 2.58 | 精确匹配 | Gelasian 底界 |
| 3.6 | 3.6 | 精确匹配 | Piacenzian |
| 2.2 | 2.195 | 插值 | 相邻控制点间线性换算 |
| 542 | 538 | 精确匹配 | 寒武 / 前寒武界线 |
| 1000 / −5 | — | 不外推 | 超出该版本控制点范围 |
