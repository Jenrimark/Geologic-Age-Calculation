# Geologic-Age-Calculation · 不同版本地质年代自动对齐模型

把某一年代表版本中的地层界线年龄，自动对齐转换到另一个年代表版本。以各版本对应的地层界线为控制点，**源版本一步直达目标版本**（不经中间版本中转，单个年龄至多插值一次），提供「一体化网页演示（含 Excel 批量上传）」「命令行批处理 / 单值查询」「只读 HTTP/JSON 接口」三种使用方式。

- 覆盖 **87** 个年代表版本（1917—2026.6）、**118** 条地层界线记录（其中 **117** 条有具名阶，第 1 行为现代界线）、**5** 级层级（宇 / 界 / 系 / 统 / 阶）。
- 纯 **R** 计算：网页版的版本列表、覆盖度图、转换结果、上传文件的批量转换全部由 R 接口完成，浏览器不做任何计算。
- 只读：服务只返回结果，**不写回、不覆盖任何原始文件**。上传的 Excel 仅写入系统临时目录、响应后即删除，转换结果以「下载」形式返回。

## 二、模型原理与演替

### 当前方案：一步直达（source → target）

1. 以源版本列中的地层界线年龄为控制点。
2. **精确匹配优先**：输入年龄等于某控制点时，直接取目标版本对应界线值。
3. **分段线性插值**：未命中时，取不大于、不小于输入年龄的相邻两个控制点，按比例线性换算到目标版本。
4. **不外推**：超出控制点范围的年龄不做外推，标记为转换失败并说明原因。
5. 按源版本就近匹配标注所属阶（Stage），仅用于核查，不参与年龄计算。

### 被替代的旧方案（已废弃）

旧版以 IUGS 2023.9 作为固定中介，走 source → IUGS → target **两步转换、两次插值**，误差逐级累积，且会把结果覆盖写回原表。现方案改为任意两版本一步直达，至多一次插值，精度更高，且只读不写。中介列已从数据表中移除，`IUGS 2023.9` 不再是可用版本。

## 三、功能特性

- **一步直达**：任意源版本直接转到任意目标版本，避免中介版本多次转换的误差累积。
- **精确匹配 + 线性插值**：命中控制点直接取值，未命中在相邻控制点间按比例换算，超范围不外推。
- **网页上传 Excel 批量转换**：拖拽或选择文件 → 自动列出工作表与列名 → 选定年龄列与转换方向 → 下载结果文件。结果文件在原表右侧追加 3 列，**绝不覆盖你上传的原文件**。
- **一体化网页**：启动 R 后自动打开浏览器，页签切换「上传批量转换」与「手动输入年龄」；关闭标签页约 90 秒后服务自动退出并清理。
- **命令行双模式**：批量处理整列年龄写回新列；或直接输入单个 / 多个年龄即时打印，不落盘。
- **只读 API**：转换能力封装为 HTTP/JSON 接口，结果仅返回，绝不写文件。
- **可追溯**：每条结果标注转换方式（精确匹配 / 插值）与就近匹配的地层单元。
- **跨平台**：自动适配 Windows、macOS 与不同用户目录，无需改代码。

### 关于上传转换的格式保留

结果文件优先用 `openxlsx` 在原工作簿上追加新列，**填充色、列宽、合并单元格等视觉格式可保留**。有一项已知限制：

> **批注无法保留。** `openxlsx` 4.2.x 的 `loadWorkbook()` 不解析批注部件。服务已做处理：保存前清理批注遗留的悬空引用，避免产出文件被 Excel 判为「已损坏」；网页也会在结果区如实提示「源文件中的批注 / 图形在转换中无法保留（数据完整）」。**数据与格式不受影响，只是批注需回原表查看。**

多工作表文件同样安全：只在你选定的那个工作表右侧追加新列，其余工作表原样保留（已实测验证）。

## 五、环境配置与启动

### 1. 安装 R

建议 R ≥ 4.0（本项目在 **R 4.5.0** 上实测通过）。

- **Windows / macOS**：到 CRAN 官网下载安装包，按默认下一步安装：<https://cran.r-project.org/>
- **macOS（Homebrew）**：`brew install --cask r`

安装后在终端验证：

```bash
Rscript --version
```

能打印版本号即安装成功。

### 2. 安装依赖包

启动 R（终端输入 `R` 进入控制台）：

**网页 / API / 上传版需要：**

```r
install.packages(c("httpuv", "jsonlite", "readxl", "openxlsx", "writexl"))
```

**命令行版需要：**

```r
install.packages(c("readxl", "dplyr", "writexl", "tibble"))
```

> 国内网络安装慢可先换镜像：`options(repos = c(CRAN = "https://mirrors.tuna.tsinghua.edu.cn/CRAN/"))` 再执行安装。
> `start-web.bat` 会自动完成上述检查与安装，Windows 用户可跳过本节。

### 3. 准备年代表数据

把统一对照总表（含 87 个版本列的 `.xlsx`）放到脚本可发现的位置。脚本不写死路径，按以下顺序查找：

1. 命令行参数 `--xlsx=文件路径`
2. 环境变量 `GEO_XLSX`
3. 脚本同目录 `docs/地质年代表.xlsx`，或同目录 `地质年代表.xlsx` / `地质年代表（表头）.xlsx`
4. 用户桌面 `~/Desktop/WJY2/地质年代表（表头）.xlsx`（日常维护版）或 `wjy.xlsx`
5. 用户桌面 `~/Desktop/归档/docs/地质年代表.xlsx`

默认情况下在仓库根目录直接运行即可自动命中 `docs/地质年代表.xlsx`，**无需传参**。

转换核心脚本 `各版本直接转换_无中介.R` 按同样思路查找（`--core=` > `GEO_CORE` > 同目录 > 桌面 `WJY2` > 桌面 `归档`）。

工作表优先取 `Sheet1`，不存在则自动取第一个工作表。

> **用户主目录探测**：Windows 下 `path.expand("~")` 可能被 `R_USER`/`HOME` 环境变量带偏到「文档」目录，脚本已改为优先用 `USERPROFILE`，其次 `HOMEDRIVE+HOMEPATH`，最后才回退 `~`，因此上述桌面路径能稳定命中。

### 4. 启动

**Windows（推荐）**：双击 `start-web.bat`。

**命令行 / macOS / Linux**：

```bash
Rscript 年代表转换_API服务.R
# 显式指定数据与端口：
Rscript 年代表转换_API服务.R --xlsx=docs/地质年代表.xlsx --port=8787
```

参数说明：

| 参数 | 默认 | 说明 |
|---|---|---|
| `--port` | `8787` | 监听端口；被占用时自动顺延至下一个空闲端口 |
| `--host` | `127.0.0.1` | 监听地址；绑 `0.0.0.0` 时同网络可访问，但服务无鉴权，勿在不可信网络长期开启 |
| `--xlsx` | 自动查找 | 年代表路径 |
| `--core` | 自动查找 | 转换核心脚本路径 |
| `--maxmb` | `40` | 单次上传体积上限（MB） |

行为：

- 启动后**自动在默认浏览器打开演示页**。若自动打开失败（依次尝试 `shell(start)` → `browseURL` → 直接调用 Edge/Chrome），窗口会**打印完整地址供手动复制**，服务本身不受影响。
- **出错时窗口停住并显示原因**，等待按键后才关闭——双击启动不会再闪退，方便截图排错。
- **关闭浏览器标签页约 90 秒后服务自动停止**（网页每 5 秒发一次 `/ping` 心跳，服务端据此判断页面是否还开着）；也可在终端按 `Ctrl+C` 手动停止。

网页操作流程：

**页签一 · 上传 Excel 批量转换**

1. 拖拽文件到虚线框，或点击选择（也支持在页面内 `Ctrl+V` 粘贴文件）。仅接受 `.xlsx` / `.xls`，上限约 40 MB。
2. 从「工作表」下拉选择要处理的表；从「年龄所在列」下拉选择年龄列（列名含「年龄 / age / 年代 / Ma」会被自动预选）。
3. 选择**源版本**（你文件里年龄所属的版本）与**目标版本**，中间 ⇄ 可一键交换。
4. 点「开始转换」→ 查看统计与预览 → 点「下载」获取结果文件。

**页签二 · 手动输入年龄**

1. 选源版本与目标版本。
2. 输入一个或多个年龄（逗号、空格、分号、顿号、**换行**均可分隔——从 Excel 复制一整列直接粘贴即可）。
3. 点「转换」，查看结果表（输入 / 输出 / 方式 / 所属地层单元）与插值数轴示意。

右栏为版本覆盖度演进柱状图（柱高 = 该版本划分的单元数 / 118，真实数据，悬停查看版本名）。

### 5. 命令行批处理 / 单值查询

```bash

```

启动后交互：

1. 列出可用版本，选择**源版本**与**目标版本**（输入列名或编号）。
2. 选择更新方式：
   - **模式 1 · 处理表格**：输入待处理文件路径与年代数据列名，批量转换后新增「目标版本 (来自源版本)」列与「_方式」列。

### `/convert`

```bash
# GET（空格需写成 %20）
curl "http://127.0.0.1:8787/convert?source=ICS%20200404&target=ICS%20202606&ages=2.59,542"

# POST
curl -X POST http://127.0.0.1:8787/convert \
  -H "Content-Type: application/json" \
  -d '{"source":"ICS 200404","target":"ICS 202606","ages":[2.59,542]}'
```

| 参数 | 说明 |
|---|---|
| `source` / `target` | 版本列名，或 `/versions` 中的序号（`1`–`87`） |
| `ages` | 数组，或逗号 / 空格 / 分号 / 顿号分隔的字符串 |

返回字段：

| 字段 | 含义 |
|---|---|
| `input` / `output` | 输入年龄、转换后年龄（Ma） |
| `method` | `精确匹配` 或 `插值` |
| `stage` | 就近匹配的所属地层单元（核查用） |
| `lower` / `upper` | 插值时的上下控制点坐标，供网页数轴绘制（精确匹配时不返回） |

> 用序号调用时注意覆盖范围：早期版本划分的单元很少（如 `Barrell1917_Elias1945` 仅覆盖 12 条），输入年龄超出其控制点范围会返回失败，不外推。

### `/inspect-file`

```bash
curl -X POST http://127.0.0.1:8787/inspect-file \
  -H "Content-Type: application/json" \
  -d '{"filename":"a.xlsx","content":"<base64>"}'
```

返回 `sheets:[{sheet, columns, rows}]`，供前端渲染工作表与列名下拉。`content` 支持带 `data:...;base64,` 前缀。

### `/convert-file`

```bash
curl -X POST http://127.0.0.1:8787/convert-file \
  -H "Content-Type: application/json" \
  -d '{"filename":"a.xlsx","content":"<base64>","sheet":"Sheet1",
       "age_column":"年龄Ma","source":"ICS 200404","target":"ICS 202606"}'
```

| 参数 | 说明 |
|---|---|
| `filename` | 原文件名，仅用于生成输出文件名 |
| `content` | 文件的 base64 |
| `sheet` | 工作表名（由 `/inspect-file` 获得）；不传则用第一个表 |
| `age_column` | 年龄所在列名（**必须**由 `/inspect-file` 获得，传列名而非单元名） |
| `source` / `target` | 同上 |

返回字段：

| 字段 | 含义 |
|---|---|
| `rows` / `converted` / `failed` / `skipped` | 总行数 / 成功 / 超出控制点范围 / 空值或非数值 |
| `new_columns` | 追加的 3 个列名：目标值、`_方式`、`_所属单元` |
| `format_preserved` | 是否走了 `openxlsx` 路径（保留填充色、列宽） |
| `comments_lost` | 源文件含批注 / 图形时为 `true`（这类内容无法保留） |
| `dangling_cleaned` | 是否清理了悬空引用（含批注源文件必为 `true`） |
| `format_note` | 面向用户的格式保留说明 |
| `preview` | 前 60 条明细：`row / input / output / method / stage` |
| `filename` / `content` | 结果文件名与 base64 内容 |

## 七、转换算法

1. **精确匹配**：输入年龄等于源版本某控制点，直接取目标列对应值。
2. **分段线性插值**：取不大于、不小于输入年龄的相邻控制点，按比例线性插值得到目标年龄。
3. **就近地层归属**：按源版本列就近匹配阶（Stage），仅标注，不参与计算。
4. 超出控制点范围**不外推**，该年龄标记失败并在结果中说明。

上传批量转换与手动输入共用同一套 `convert_age()`，结果完全一致；两者都不修改转换算法本身。

## 九、常见问题

**Q：双击 `start-web.bat` 只弹出黑窗口、没有网页？**
先看窗口里的文字：现在出错会**停住并显示原因**，不会闪退。最常见的是端口被占用——服务会自动顺延端口并打印实际地址，照着窗口里的 `http://127.0.0.1:xxxx/` 打开即可。若显示找不到 R，按「五、1」安装并勾选加入 PATH。

**Q：启动后提示「未找到年代表」？**
用 `--xlsx=` 显式指定年代表完整路径，或设置环境变量 `GEO_XLSX`。

**Q：端口 8787 被占用？**
无需处理，服务会自动顺延到 8788、8789…并在窗口打印实际监听地址，浏览器随之打开。也可显式 `--port=8800` 指定。

**Q：上传后提示「不是有效的 Excel 文件」？**
仅支持 `.xlsx` / `.xls`。CSV 请先在 Excel 中另存为 `.xlsx`。

**Q：上传后提示「没有任何年龄转换成功」？**
多半是选的年龄列不是数值，或该列年龄超出所选源版本的控制点范围。换一个覆盖更广的源版本（ICS 系列覆盖最全），或先用页签二手动试一个年龄确认范围。

**Q：下载的结果文件里批注不见了？**
如「三、关于上传转换的格式保留」所述，`openxlsx` 不解析批注部件，批注无法保留（数据与填充色等格式不受影响）。需要批注请回原表查看。

**Q：网页显示「未连接 R 服务」？**
说明 R 服务未启动或已停止；重新运行 `start-web.bat`（或方式 A 的命令）即可，浏览器不自行计算。

**Q：关掉标签页后服务还在跑吗？**
不会。网页每 5 秒发一次心跳，服务端连续 90 秒收不到即自动退出并清理端口。若浏览器始终没能自动打开（从未发过心跳），服务不会自杀，需手动 `Ctrl+C`。

**Q：刷新页面会不会把服务关掉？**
不会。刷新后心跳立即恢复，只有真正关闭标签页才触发自动退出。

**Q：绑了 `0.0.0.0` 别人能访问吗？**
能，但服务无身份验证，仅限可信内网演示，演示完及时关闭。

**Q：上传的文件会被保存到服务器吗？**
只写入系统临时目录（`tempfile()`），响应返回后立即 `unlink` 删除；转换结果以 base64 随响应返回，由浏览器生成下载。**服务不会修改你上传的原文件，也不会在仓库内留下副本。**

## 十、已修复的问题（供追溯）

| 问题 | 影响 | 修复 |
|---|---|---|
| `get_arg("xlsx")` 缺第二个参数 | 不带 `--xlsx=` 启动即崩溃（R 惰性求值触发 `argument "default" is missing`） | 改为 `get_arg(key, default = "")`，并保留显式传参优先 |
| 使用 `wb$getSheetNames()` | openxlsx 4.2.x 无此方法，返回 NULL 后被兜底成第 1 个表，**多工作表文件会把结果误写进第一个表** | 改用正确字段 `wb$sheet_names`，定位失败时明确报错而非静默写错 |
| 悬空 drawing / vml 引用 | 含批注的源文件经往返后，Excel 提示「文件已损坏，是否修复」，openpyxl 等严格解析器直接打不开 | 保存前删除指向未打包部件的关系，并清空 worksheet 上的 `drawing` / `legacyDrawing` 标签 |
| `workbookView` 空属性 | `xWindow=""` 等空串不符合 OOXML（应为整数），严格解析器报错 | 保存前补为 `0` |
| 新列表头竖排 | 三个列名以字符向量传入 `writeData`，被当成「一列三行」 | 改为 `data.frame` 一次写入 |
| `<<-` 超赋值误用 | `tryCatch({})` 块在当前函数环境求值，`<<-` 会去父环境找变量、找不到就在全局环境新建，导致状态标志恒为假且**并发请求互相污染** | 改为普通赋值 `<-`（已实测复现并验证） |
| 端口占用即退出 | 双击启动时若端口已被占用，窗口一闪而过，看不到任何原因 | 端口自动顺延；出错时打印原因并等待按键 |
| 自动退出逻辑失效 | 原实现由服务自己探测 `/health`，自己请求自己永远成功，检测不到页面关闭 | 改为网页 `/ping` 心跳；从未收到心跳则不自杀 |
