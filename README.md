# Geologic-Age-Calculation · 不同版本地质年代自动对齐模型

把某一年代表版本中的地层界线年龄，自动对齐转换到另一个年代表版本。以各版本对应的地层界线为控制点，**源版本一步直达目标版本**（不经中间版本中转，单个年龄至多插值一次），提供「一体化网页演示」「命令行批处理 / 单值查询」「只读 HTTP/JSON 接口」三种使用方式。

- 覆盖 **87** 个年代表版本（1917—2026.6）、**118** 个地层单元、**5** 级层级（宇 / 界 / 系 / 统 / 阶）。
- 纯 **R** 计算：网页版的版本列表、覆盖度图、转换结果全部由 R 接口返回，浏览器不做任何计算。
- 只读：服务只返回结果，不写回、不覆盖任何原始文件。

---

## 一、模型原理与演替

### 当前方案：一步直达（source → target）

1. 以源版本列中的地层界线年龄为控制点。
2. **精确匹配优先**：输入年龄等于某控制点时，直接取目标版本对应界线值。
3. **分段线性插值**：未命中时，取不大于、不小于输入年龄的相邻两个控制点，按比例线性换算到目标版本。
4. **不外推**：超出控制点范围的年龄不做外推，标记为转换失败并说明原因。
5. 按源版本就近匹配标注所属阶（Stage），仅用于核查，不参与年龄计算。

### 被替代的旧方案（已废弃，存于 `历史/`）

旧版以 IUGS 2023.9 作为固定中介，走 source → IUGS → target **两步转换、两次插值**，误差逐级累积，且会把结果覆盖写回原表。现方案改为任意两版本一步直达，至多一次插值，精度更高，且只读不写。

---

## 二、功能特性

- **一步直达**：任意源版本直接转到任意目标版本，避免中介版本多次转换的误差累积。
- **精确匹配 + 线性插值**：命中控制点直接取值，未命中在相邻控制点间按比例换算，超范围不外推。
- **一体化网页（答辩主用）**：启动 R 后自动打开浏览器，单屏三栏展示，关闭标签页即自动停止服务并清理。
- **命令行双模式**：批量处理整列年龄写回新列；或直接输入单个 / 多个年龄即时打印，不落盘。
- **只读 API**：转换能力封装为 HTTP/JSON 接口，结果仅返回，绝不写文件。
- **可追溯**：每条结果标注转换方式（精确匹配 / 插值）与就近匹配的地层单元。
- **跨平台**：自动适配 Windows、macOS 与不同用户目录，无需改代码。

## 四、环境配置

### 1. 安装 R

建议 R ≥ 4.0。

- **Windows / macOS**：到 CRAN 官网下载安装包，按默认下一步安装：<https://cran.r-project.org/>
- **macOS（Homebrew）**：`brew install --cask r`

安装后在终端验证：

```bash
Rscript --version
```

能打印版本号即安装成功。

### 2. 安装依赖包

启动 R（终端输入 `R` 进入控制台），按使用方式安装对应包：

**命令行版需要：**

```r
install.packages(c("readxl", "dplyr", "writexl", "tibble"))
```

**一体化网页 / API 版需要：**

```r
install.packages(c("httpuv", "jsonlite", "readxl"))
```

两套都用就一次性装齐：

```r
install.packages(c("readxl", "dplyr", "writexl", "tibble", "httpuv", "jsonlite"))
```

> 国内网络安装慢可先换镜像：`options(repos = c(CRAN = "https://mirrors.tuna.tsinghua.edu.cn/CRAN/"))` 再执行安装。

### 3. 准备年代表数据

把统一对照总表（含 87 个版本列的 `.xlsx`）放到脚本可发现的位置。两个脚本都不写死路径，按以下顺序查找：

1. 命令行参数 `--xlsx=文件路径`
2. 环境变量 `GEO_XLSX`
3. 脚本同目录 `docs/地质年代表.xlsx`，或同目录 `地质年代表.xlsx`
4. 脚本同目录下的 `地质年代表（表头）.xlsx` 或 `wjy.xlsx`（旧示例，兼容保留）
5. 用户目录 `~/Desktop/WJY2/`（Windows 与 macOS 用户目录由系统自动展开）

默认情况下直接运行即可自动命中仓库内 `docs/地质年代表.xlsx`，无需传参。

工作表优先取 `Sheet1`，不存在则自动取第一个工作表。

## 五、启动方式

### 方式 A · 一体化网页演示（答辩主用，推荐）

在仓库根目录执行（默认自动命中 `docs/地质年代表.xlsx`，可省略参数）：

```bash
Rscript 年代表转换_API服务.R
# 显式指定数据：Rscript 年代表转换_API服务.R --xlsx=docs/地质年代表.xlsx
```

**Windows 一键启动**：双击根目录 `start-web.bat`，自动定位 R、按需安装依赖（清华镜像）并启动服务、打开浏览器；关闭窗口即停止。

行为：

- 启动后**自动在默认浏览器打开演示页**，无需手动开文件，无跨域问题。
- **关闭浏览器标签页即自动停止 R 服务并清理接口**；也可在终端按 `Ctrl+C` 手动停止。

参数说明：

| 参数 | 默认 | 说明 |
|---|---|---|
| `--port` | `8787` | 监听端口 |
| `--host` | `127.0.0.1` | 监听地址；绑 `0.0.0.0` 时同网络可访问，但服务无鉴权，勿在不可信网络长期开启 |
| `--xlsx` | 自动查找 | 年代表路径 |
| `--core` | 同目录核心脚本 | 转换核心脚本路径 |

> 已用 `--xlsx` 指定，或设置了 `GEO_XLSX` 环境变量时可省略该参数。

网页操作流程：

1. 左栏选**源版本**（输入年龄所在版本）与**目标版本**（结果版本），中间 ⇄ 可一键交换。
2. 输入一个或多个年龄（Ma，逗号分隔），点「转换」。
3. 中栏看一步直达箭头、结果表（输入 / 输出 / 方式 / 所属地层单元）与插值数轴。
4. 右栏为 87 版本覆盖度演进柱状图（柱高 = 该版本划分单元数 / 118，真实数据）。

### 方式 B · 命令行批处理 / 单值查询

```bash
Rscript 各版本直接转换_无中介.R
# 显式指定：Rscript 各版本直接转换_无中介.R --xlsx=docs/地质年代表.xlsx
```

启动后交互：

1. 列出可用版本，选择**源版本**与**目标版本**（输入列名或编号）。
2. 选择更新方式：
   - **模式 1 · 处理表格**：输入待处理文件路径与年代数据列名，批量转换后新增「目标版本 (来自源版本)」列与「_方式」列。
   - **模式 2 · 直接输入年龄**：输入一个或多个年龄（空格 / 逗号 / 分号 / 顿号分隔），即时打印结果，不写文件。

示例：

```bash
Rscript 各版本直接转换_无中介.R --xlsx=./wjy.xlsx
# 选好源/目标版本后，模式 2 输入：251.4 250.7
```

### 方式 C · 直接调用 API

服务启动后用任意 HTTP 客户端访问：

```bash
# GET
curl "http://127.0.0.1:8787/convert?source=GTS2004&target=GTS2020&ages=2.59,2.2"

# POST
curl -X POST http://127.0.0.1:8787/convert \
  -H "Content-Type: application/json" \
  -d '{"source":"GTS2004","target":"GTS2020","ages":[2.59,2.2]}'
```

## 六、接口说明

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/` | R 托管的演示网页 |
| GET | `/api` | 接口说明（JSON） |
| GET | `/health` | 健康检查：行数、列数、版本数、只读状态 |
| GET | `/versions` | 版本列表，每项含 `index / name / cover`（cover = 该版本非空单元数） |
| GET/POST | `/convert` | 转换；GET 用查询串，POST 用 JSON body |
| GET | `/shutdown` | 停止服务并清理（关闭页面时由前端自动调用） |

`/convert` 返回字段：

| 字段 | 含义 |
|---|---|
| `input` | 输入年龄（Ma） |
| `output` | 转换后年龄（Ma） |
| `method` | `精确匹配` 或 `插值` |
| `stage` | 就近匹配的所属地层单元（核查用） |
| `lower` / `upper` | 插值时的上下控制点坐标，供网页数轴绘制 |

## 七、转换算法

1. **精确匹配**：输入年龄等于源版本某控制点，直接取目标列对应值。
2. **分段线性插值**：取不大于、不小于输入年龄的相邻控制点，按比例线性插值得到目标年龄。
3. **就近地层归属**：按源版本列就近匹配阶（Stage），仅标注，不参与计算。
4. 超出控制点范围**不外推**，该年龄标记失败并在结果中说明。

## 八、常见问题

**Q：启动后提示「未找到年代表」？**
用 `--xlsx=` 显式指定年代表完整路径，或设置环境变量 `GEO_XLSX`。

**Q：端口 8787 被占用？**
加 `--port=8788` 换端口；网页由 R 同源托管，端口改了浏览器会随启动地址打开，无需手动改前端。

**Q：包安装失败 / 加载报错？**
确认已按「四、环境配置」安装对应包；换清华镜像重试；`library(包名)` 单独跑一次看具体报错。

**Q：网页显示「未连接 R 服务」？**
说明 R 服务未启动或已停止；回到终端重新运行方式 A 的命令即可，浏览器不自行计算。

**Q：刷新页面会不会把服务关掉？**
正常关闭标签页才触发 `/shutdown`；若刷新偶发停止，重新启动 R 命令即可。

**Q：绑了 0.0.0.0 别人能访问吗？**
能，但服务无身份验证，仅限可信内网演示，演示完及时关闭。
